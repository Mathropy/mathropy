There are necklace with $n$ beads. Mark each beads with $1~n$, using each number once. For each number $k$, sum of the marked number of two beads that connected with beads marked $k$ must be multiple of $n$.

For example, consider $n=4$. Then $1-2-3-4-1$ is possible, but $1-2-4-3-1$, $1-3-2-4-1$ is not possible.

**Questions**
- For which values of $n$ does such a configuration exist?

<details style="margin-bottom: 1.0rem !important;">
  <summary>Hint! (Click!)</summary>
  $1-2-3-\cdots-n-1$ is one of answers.
</details>

  $1-2-3-\cdots-n-1$, $1-2-3-\cdots-n-(2n+1)-(n+1)-(n+2)-\cdots-2n-1$ are only possible cases. I'll skip the detailed proof for now and add it later.
